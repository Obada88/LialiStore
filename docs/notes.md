# Project Notes

## Biggest Challenge

The main challenge was running Docker in my development environment.
Docker Desktop could not be installed on my Windows device, so I used GitHub Codespaces to build and run the Docker container successfully.

## What I Learned

- How to create a Dockerfile.
- How to build a Docker image.
- How to run a container and expose a port.
- How to use GitHub Codespaces for development.
- Why rebuilding the Docker image is necessary after changing project files.

## Conclusion

This assignment helped me understand the basic Docker workflow and how to manage and publish a project using GitHub.
