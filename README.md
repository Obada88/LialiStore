# LialiStore
Turkish-Saudi Store
مرحبًا بكم في مشروع متجر تركي سعودي إلكتروني! هذا المتجر مصمم خصيصًا لتلبية احتياجات النساء في السعودية والإمارات، ويقدم مجموعة من المنتجات الفاخرة مثل البيجامات الحرير والقطن.

محتويات المشروع
src/: يحتوي على جميع ملفات المصدر الخاصة بالمتجر.

assets/: يحتوي على الخطوط والصور المستخدمة في الموقع.
fonts/: يحتوي على ملف CSS لخطوط Cairo و Tajawal.
images/: يحتوي على الصور المستخدمة في المنتجات والعلامة التجارية.
css/: يحتوي على ملف TailwindCSS لتصميم الموقع.
js/: يحتوي على ملفات JavaScript لإدارة الوظائف المختلفة.
main.js: الملف الرئيسي لتشغيل التطبيق.
supabase.js: لإدارة التفاعل مع قاعدة بيانات Supabase.
cart.js: لإدارة سلة التسوق.
checkout.js: لمعالجة عملية الدفع.
admin.js: لإدارة لوحة التحكم الخاصة بالمدير.
rtl.js: لضمان عرض النصوص من اليمين لليسار.
index.html: الصفحة الرئيسية للمتجر.
product.html: صفحة تفاصيل المنتج.
cart.html: صفحة سلة التسوق.
checkout.html: صفحة الدفع.
order-success.html: صفحة تأكيد الطلب.
about.html: صفحة "من نحن".
contact.html: صفحة "تواصل معنا".
admin/: يحتوي على صفحات لوحة التحكم الخاصة بالمدير.
login.html: صفحة تسجيل دخول المدير.
dashboard.html: صفحة عرض الطلبات.
edit-home.html: صفحة تعديل محتوى الصفحة الرئيسية.
supabase/: يحتوي على ملف SQL لإنشاء قاعدة البيانات.

tailwind.config.js: ملف إعدادات TailwindCSS.

package.json: ملف إعدادات npm للمشروع.
